## 4. 未修项与理由

### 4.1 第15条 的残余：SIGKILL 崩溃仍会重复扣一次料（**部分修**）

`craft_retry_ledger_ab.mjs` 的 B 场景如实记录：

```
改后：跑了 2 次 → 扣料 6 个原木（第一次的产出没机会记账）｜state=done producedTotal=3
PASS B-如实记录：SIGKILL（没走到 finish）这一类本修复覆盖不到，仍有 1 次重复扣料
```

理由：产出账是记在 `finish` 里的；进程在 `finish` 之前被 SIGKILL，那次产出根本没机会写库。

### 10.2 `git-rescue` 的最终处置与理由

| 文件 | 处置 | 理由 |

该补丁的价值是**判据的书面记录**，不是"可直接打上"——不写明这点，下一个人照着敲会以为补丁坏了。
