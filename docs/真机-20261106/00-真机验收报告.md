### 4.3 结论射程（被 Lead 追问后收窄，重要）

追问「old 臂 `seq1b/1c` 为何 `preventDefault=true` 却不发送」后查实：**不是探针漏统计**。

`send()` 读的是 **ref 而非 DOM**；Vue 的 `vModelText` 在组合期遇到 `e.target.composing` 直接 return，**不把组合文本写回 ref** ⇒ `text` 为空 ⇒ `if (!text) return`。
证据：组合中 DOM 里有字，但发送按钮 `disabled=true`（该按钮只由 `input.trim()` 决定）；组合中点按钮无效、聊天为空；先上屏再组合回车才发出 `["你好"]`。

⇒ 因此结论**只能**这样写：
- 旧版**只在「已上屏中文 + 续输组合」时**才把半句发出去（`seq1f` 已复现）；
- **任何组合态回车都会抢走 IME 默认行为**（`preventDefault`）——这半伤害在 1b/1c 也被观测到；
- **不能**笼统写成「旧版会发送半句拼音」。

## 11. 下次重跑时怎么把环境拉起来（含两个已踩过的坑）

服务端与面板可以用 `T2/start-env-r3.ps1` 拉起（**命令立刻返回**，另开调用轮询日志）：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "docs\真机-20261106\T2\start-env-r3.ps1"
```

**两条实操注意（脚本里都注释了）**：
1. **启动与等待要分开**：`Start-Process` 起服务后**立刻返回**，另开一次调用去轮询 `Done (`。把 `sleep`/等待塞进同一次调用会让启动和轮询耦合，调用一超时就得从头再来。
2. **不要**在 `.ps1` 里写中文路径字面量 —— PowerShell 5.1 按 GBK 解码无 BOM 的 UTF-8，`真机-20261106` 会变成 `鐪熸満-20261106` → `MODULE_NOT_FOUND`。脚本改为从 `$PSScriptRoot` 推导。

**优雅关服**：面板 → `Stop-Process` → RCON `stop`（**别用 `-Force` 关 Paper**，会跳过世界保存）。
