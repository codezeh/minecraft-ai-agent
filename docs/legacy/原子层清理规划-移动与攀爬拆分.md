# 原子拆分规划：移动 与 攀爬 彻底分开

> 用户判断（2026-10-25）：
> 「你把爬和移动这俩拆成原子不就可以了？」
>
> 这是根治办法。现状是 `moveTo` 通过 pathfinder 的 `climbables`
> **顺便具备了攀爬能力** —— 爬是"移动的副作用"，不是显式动作。
> 只要爬还能被移动顺带触发，就永远会出"路过藤蔓被顶上去"这类问题。

---

## 1. 现状问题

| 层 | 现在的行为 | 问题 |
|---|---|---|
| `moveTo` | 调 `makeMovements`，其中 `climbables` 含 ladder/vine | 移动**顺便能爬** |
| pathfinder | 认为"爬上去"是合法路线，会主动规划 | 路线里出现"爬上藤蔓" |
| 物理 | 藤蔓=梯子，`isCollidedHorizontally` 就抬升 | 一碰就上升 |

**三处都在"顺便爬"**，任一处没管住就会复现。

## 2. 拆分方案

### 2.1 `moveTo` —— 只走，不爬

```js
moveTo(bot, target, { tol, timeout, canDig }) -> ActionResult
```

- **`climbables` 里只保留 ladder**（人放的梯子算"路"）
- 藤蔓、垂泪藤等**一律不算路**
- 遇到必须爬才能过的地方 → 返回 `NO_PATH`，**明确失败**，不偷偷爬

**这是关键**：`NO_PATH` 是诚实报告。上层看到它，才知道"这里需要爬或者需要清障"。

### 2.2 `climbTo` —— 显式攀爬原子（新增）

```js
climbTo(bot, target, { maxClimb, timeout, kind }) -> ActionResult
```

| 字段 | 说明 |
|---|---|
| `kind` | `'ladder'` / `'vine'`，默认按脚下方块自动判断 |
| `maxClimb` | 最多爬几格，默认 8 |
| 成功判据 | **y 达到目标** 且 站稳（`standable`） |
| 失败码 | `NO_SUPPORT`（脚下不是可爬方块）/ `BLOCKED`（爬不上去）/ `TIMEOUT` |

实现要点：
- 打开 `bot.vinePhysics.setClimbing(true)`，让物理把藤蔓当梯子
- 按 jump + forward，或 pathfinder + `allowVineClimb: true`
- **结束后必须 `setClimbing(false)`**（`finally` 里），否则会污染后续移动

### 2.3 调用方的选择变明确了

```js
// 想去砍树：
const mv = await moveTo(bot, standSpot);
if (mv.code === 'NO_PATH') {
    // 明确知道"走不过去"，可以选择：
    //   a) 清障（skill_clear）再试
    //   b) 爬上去（climbTo）
    //   c) 换目标
}
```

**这才是用户说的"简单步骤"**：
规划到木头周围 → 识别是否目标树 → 识别是否有遮盖 → 有就清 → 没有就砍。

## 3. 范围

| 步 | 内容 | 风险 |
|---|---|---|
| 1 | `makeMovements` 默认不含藤蔓（已做，但语义要改清楚） | 低 |
| 2 | 新增 `atom_climb.js`：`climbTo` + 测试 | 中 |
| 3 | `planCollect` 里 `moveTo` 失败时，加"清障后重试"的降级 | 中 |
| 4 | 全套验收 + 主服基线 | — |

## 4. 验收标准

| # | 判据 |
|---|---|
| 1 | `moveTo` 遇到只能爬的地方 → 返回 `NO_PATH`（不偷偷爬） |
| 2 | `climbTo` 爬梯子成功、爬藤蔓成功、爬不上去返回明确错误码 |
| 3 | `climbTo` 结束后 `vinePhysics` 复位（不污染后续移动） |
| 4 | 真实丛林现场：走到树旁全程**无原地攀爬** |
| 5 | 全套 17/17 + 主服基线不退化 |

## 5. 判断标准（固化）

> **一个原子只能有一个"能力"，不能有"顺便"。**

| 检查 | 不合格 |
|---|---|
| 能力 | `moveTo` 顺便能爬 → 拆 |
| 失败语义 | 走不到却偷偷爬上去 → 必须报 `NO_PATH` |
| 状态复位 | 爬完没复位 → 污染后续 |
