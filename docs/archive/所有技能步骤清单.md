# 所有技能按「枚举→执行→校验→降级」模型的步骤清单

> 这不是流水线，是**循环**：枚举目标 → 取一项 → 查状态 → 执行原子（自带前置断言）→ 校验后置 → 失败降级。
> 每个技能都标：**目标从哪来**、**单项做什么**、**凭什么算成功**、**失败了退到哪**。
>
> 行号可核对。命令名来自 `src/agent/commands/`（共 58 个）。

---

## 零、先记住三个统一的概念

```
目标项 (Item) = { kind, pos, expect, state }
  kind    'block' | 'entity' | 'cell' | 'point' | 'slot'
  pos     方块/实体/坐标
  expect  期望变成什么（'air' / 'oak_planks' / 到达 / 持有）
  state   'todo' | 'done' | 'failed'

原子返回 (Result) = { ok, code, message, data }
  data: { target, from, dist, count, costMs, pre:{}, post:{} }

降级策略 (Policy) = { 错误码: 动作 }
  'restep' 换站位重试 · 'next' 下一项 · 'rescan' 重新枚举
  'wait'   等一会儿重试 · 'abort' 整体放弃并如实报告
```

## 一、采集类

### 1. `collect`（!collectBlocks）— 678 行 → 目标 ~150 行

| 环节 | 内容 |
|---|---|
| **枚举** | 侦察：找全部原木坐标 → 去重 → 按树干聚成树 → 每棵树给出格子列表<br>排序：距离绝对优先（差>5格纯按距离） |
| **取一项** | 取下一棵树的下一格 |
| **查状态** | 这格还是原木吗？在黑名单吗？在保护区吗？<br>**是天然树吗**（树冠 + 人工材料）—— 唯一的"辨别" |
| **执行** | ① 站到能挖的位置（接力搜索：邻位→下方仰角→远臂展）<br>② 清视线上的藤蔓/树叶<br>③ 挖<br>④ 捡掉落物 |
| **校验** | 这格现在是空气了吗？背包 count 增加了吗？ |
| **降级** | `OUT_OF_REACH`/`NO_PATH` → 换站位重试（1次）→ 仍失败则丢这格<br>`NO_TOOL` → 造/找工具后重试<br>`BLOCKED` → 等 300ms 重试<br>这棵树格子全丢 → 下一棵<br>树林全砍完 → 重枚举（扩半径） |

**要删的三处**：兜底扫描（和枚举重复）、备用挖掘（和"换站位"重复）、第三条挖掘路径。

## 八、汇总：按结构分类的全部技能

| 结构 | 技能 | 数量 |

| **单原子**（1 个动作 + 1 个断言） | equip/discard/consume/givePlayer/placeHere/breakBlockAt/goToCoordinates/walkTo/lookAt | ~10 |

## 十、统一后的原子清单（我建议最终形态）

```
感知（只读，返回裸值或数据）
  blockAt / findBlocks / countItems / distanceTo / findEntities

动作（返回 Result，自带前置断言 + 后置校验）
  moveTo(target, tol)        → pre: 有路 · post: 到达
  digBlock(pos)              → pre: 可达+可挖 · post: 是空气
  placeBlockAt(pos, item)    → pre: 有材料+有支撑+没占位 · post: 是该方块
  equipItem(name)            → pre: 背包有 · post: 手持该物品
  useItemAt(pos)             → pre: 手持可交互 · post: 方块状态变化
  attackEntity(entity)       → pre: 在范围内 · post: 目标死亡/远离
  openContainer(pos)         → pre: 是容器 · post: 窗口打开
```

**就这 7 个动作原子。** 所有复合都由它们 + 循环 + 降级策略组成。
