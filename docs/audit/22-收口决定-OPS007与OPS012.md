## OPS-007 · 依赖锁入库 —— **已完成**

### 为什么不能直接 `git add -f`
先做离线比对（改之前那份 lock）：

| 项 | 结果 |
|---|---|
| `@eslint/js` / `eslint` / `eslint-plugin-no-floating-promise` / `globals` | package.json 是 **devDependencies**，lock 根条目把它们记在 **dependencies** |
| `mineflayer` | package.json 精确 `4.39.0`，lock 根条目录的是 `^4.39.0` |

这样的 lock 一旦入库，`npm ci` 会以 **not in sync** 失败 —— 等于把"能装"换成"装不上"，
而且 `patches/mineflayer+4.39.0.patch` 是按精确版本打的，漂移就是错的补丁。

### 怎么做的
1. `npm install --package-lock-only --prefer-offline` 重新生成；
2. 再比对：dependencies 34/34、devDependencies 5/5、版本串 0 处不同、直接依赖无缺失；
3. 漂移评估：**548 个包条目零增减、零版本变化**，`resolved` 里的镜像地址原样保持
   ⇒ 只修元数据，实际依赖树未动；
4. `.gitignore` 末尾加 `!package-lock.json` 例外（必须排在第 4 行忽略规则之后，与仓库
   已有 `!.env.example` 同一做法），并写清入库理由；
5. `start.bat` 文案同步：原来写"本仓不跟踪锁"，已不成立 → 改成"这个检出缺了被跟踪的锁，
   从 git 恢复"；`npm install` 降级分支保留（用户删锁/解压旧包时仍能装）。

### 验收证据（不是"应该行"）
用 `git worktree add` 做了一个**等价于新 clone 的干净检出**（有 lock、有 patches、无 node_modules）：

```
npm ci --dry-run --ignore-scripts --no-audit --no-fund
→ added 548 packages in 425ms   (exit 0)
```

`--ignore-scripts` 是**为了隔离 postinstall 的 `patch-package`**（干净检出里 devDependencies
还没装，脚本本身当然跑不了；这是 dry-run 的固有现象，与锁是否同步无关）。
真实安装时 `patch-package` 会随 `npm ci` 一起装好再执行。

- 提交：核心仓 `a5446ce`
- `npm run gate` 通过（preflight + lint:hard + 审计正则 + 补丁完整性）

### 未做（保持原状，是另一个决策）
**没有切回官方源**：仍是 npmmirror。代价是可复现性绑定镜像可达性；
彻底解决要"切官方源 + 重生成 lock"一起做。当前选择是保持日常安装速度。

## OPS-012 · 世界备份 —— **按用户决定：不做**

用户明确答复（2026-11-06）：**"服务器这个不用备份，都是用来测试的地图"**。

因此本项按"**用户已接受该风险**"闭环，不再列为待修：

- 不建立定期备份，不做恢复演练，不修改 `server/` 运行时数据；
- 已交付的两个脚本**保留为可选工具**（不是残留代码，随时可用来拍一次快照）：
  - `scripts/backup-world.ps1`：RCON `save-off` → `save-all flush` → 压缩 world*/bots
    → manifest + SHA256，`finally` 里一定 `save-on`；RCON 不可用时降级为直接压缩并**明确告警**。
  - `scripts/verify-world-backup.ps1`：**只读**核验（manifest 大小/SHA256、zip 内
    level.dat 与 region/*.mca、解压到系统临时目录验 gzip 头与 mca 长度），绝不碰真实世界。
  - 两者都用构造夹具做过 **PASS / FAIL 双向实测**（正常备份 10 项全过；把 mca 改成 100 字节
    的残缺备份能准确报错并返回退出码 1）。
- 结论口径：**风险已知且被用户接受**，不是"已修复"，也不是"遗漏"。
  如果哪天这张地图变成要长期保留的成果，重开本项即可 —— 脚本已就位。
