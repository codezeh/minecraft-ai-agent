#### C.5 一条**测量方法**教训（我差点据此误报 BLOCK）
我第一次测 `lint_hard.mjs` 用了 `node tools/lint_hard.mjs 2>&1 | tail -6; echo EXIT=$?` → 打出 **EXIT=0**，看上去是"门禁跑不动却返回成功"的假绿（那会是 BLOCK 级）。
**实际是我测错**：`$?` 取到的是管道最后一个命令（`tail`）的退出码。改成 `node tools/lint_hard.mjs > file 2>&1; echo EXIT=$?` → **真实 exit=1**。
→ 建议写进 `REVIEW-PROTOCOL` §3.5 同级：**凡断言"门禁 exit 码"，命令里不许有管道**（`| tail`/`| grep` 会吞掉被测程序的退出码）。
