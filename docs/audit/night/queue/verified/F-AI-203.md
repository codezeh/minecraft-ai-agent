  ## 二、存盘：原文写进 memory.json，无过滤
  `history.js:126-149 save()`：
  ```js
  const data = { memory: this.memory, codeVersion: MEMORY_CODE_VERSION, turns: …, … };

  ```
  唯一的"清洗"是 `capSize`（20 KB 上限 + 1500 字截断），**只限长度，不过滤内容**。

  ## 三、回流：每轮提示都注入
  `prompter.js:206-207`：
  ```js
  if (prompt.includes('$MEMORY')) prompt = prompt.replaceAll('$MEMORY', this.agent.history.memory);
  ```
  而 `$MEMORY` 出现在**所有 profile 的 conversing 模板**里（实测 `profiles/my-local.json` 结尾就是 `Summarized memory:'$MEMORY'`）。
  ⇒ 一轮注入成功后，此后**每一次**对话都带着它 —— 这就是"持久污染"。
  污染的生命周期：只在 `codeVersion` 变更时被丢弃（`history.js:11` 注释："版本不符就丢弃 memory 里的经验结论"）
  ⇒ 只要不改代码版本，污染可以存活很久。
