## 5.3 「0600 在 Windows 是否有效」直接实验（临时文件）
$ echo ... > tmp/r5-deploy/acltest/secret.test.json
$ icacls（chmod 前）
tmp\r5-deploy\acltest\secret.test.json S-1-4-48068235-1068318981:(I)(W,D,DC)
                                       BUILTIN\Administrators:(I)(F)
                                       NT AUTHORITY\SYSTEM:(I)(F)
                                       NT AUTHORITY\Authenticated Users:(I)(M)
                                       BUILTIN\Users:(I)(RX)
                                       Mandatory Label\Low Mandatory Level:(I)(NW)

Successfully processed 1 files; Failed processing 0 files
$ chmod 600 secret.test.json
$ ls -l（chmod 后）
-rwxrwxrwx 1 zeh zeh       31 Nov  8 15:31 tmp/r5-deploy/acltest/secret.test.json
$ icacls（chmod 后）
tmp\r5-deploy\acltest\secret.test.json S-1-4-48068235-1068318981:(I)(W,D,DC)
                                       BUILTIN\Administrators:(I)(F)
                                       NT AUTHORITY\SYSTEM:(I)(F)
                                       NT AUTHORITY\Authenticated Users:(I)(M)
                                       BUILTIN\Users:(I)(RX)
                                       Mandatory Label\Low Mandatory Level:(I)(NW)

Successfully processed 1 files; Failed processing 0 files
→ chmod 前后 ACL 完全一致（连 ls 的 -rwxrwxrwx 也没变）⇒ POSIX 0600 在 NTFS ACL 上不生效。
