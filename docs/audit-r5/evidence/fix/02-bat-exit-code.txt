## 设计要点：为什么不用 if errorlevel 1 ( ... exit /b %errorlevel% )
   cmd 会在进入括号块**之前**就把 %errorlevel% 展开，块内拿到的是旧值。
   这里改成：先 if not errorlevel 1 exit /b 0（成功路径直出 0），
   失败时 set "RC=%errorlevel%" 在**块外**执行（展开时即当前值），再 pause、再 exit /b %RC%。
   全程不需要 enabledelayedexpansion，也不影响 setlocal。
