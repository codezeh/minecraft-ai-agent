## 三条最重要的结论（如果只记三件事）

**1. 规则必须有出处，不许凭想象。**
`src/agent/rules/game_rules.json` 里 18 条规则，每条带 R1/R2/R3 来源级别和证据脚本。
没有出处的判断不许进代码。这条是从"凭空写树会塌、白写 110 行"换来的。

**2. 允许升级依赖，优先于自己打补丁。**
BUG-001 花了 3 小时调服务端配置、写物理兜底，全没用；查了一下 npm 有没有新版本，问题消失。

**3. 原子要最小但可维护，不是越小越好。**
"爬一格"这种原子在藤蔓上物理不成立（松手就滑落），拆太细反而不可维护。
